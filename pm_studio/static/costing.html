Time & cost

A declared capacity, split across projects by the activity each person generated.

These hours are a distribution, not a measurement. Nobody's screen time is being timed. Each person's declared weekly capacity is split across projects in proportion to the activity they generated, so the totals always reconcile to a real week — and any figure can be overridden below.

Labour and agent cost are kept apart on purpose. Labour is an estimate (hours × rate). Agent cost is measured from the model's own reported token spend. An agent running for twenty minutes while nobody is at the keyboard is machine time, not someone's afternoon.
